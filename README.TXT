Here are a few things you should know about Uprising:

- Uprising requires Direct X 5.0.  YOU MUST HAVE DIRECT X 5.0 
  TO INSTALLED TO PLAY UPRISING.  If you don’t have Direct X 
  5.0, don’t worry.  We’ve included it on the disc. 

- If you're on a 16 meg machine and you play many levels (15+)
  in a row without restarting Uprising (exiting the program and
  restarting) you might experience a crash. We were unable to 
  isolate and fix this before shipping Uprising 1. Look for a
  patch disk in the near future with this fix. 

- Minimum requirements for Uprising are a P90 w/16MB RAM.

- Recommended requirements for Uprising are a P133 w/32 MB RAM.

- You will need 90 MB of free hard drive space to install Uprising.

- If the game crashes often, check your free hard drive space on your
  primary drive. If you have too little free space (less than about 50 
  megs -- or the swap file size you set in Win 95) free more hard drive 
  space by deleting unnecessary programs (like other companys' games!).

- If you experience problems with the Hercules Dynamite 128, Matrox 
  Millennium I or II, Matrox Mystique, or the S3 Trio 32 / 64 or the S3 
  Virge video cards, please visit our website at 
  www.3do.com\customerservice.  We have links to these companies 
  websites so you can download the latest drivers.  Direct X 5.0 didn’t 
  have the latest drivers for these video cards and since we’re a Direct X 
  5.0 game, we’ll need them to run.  So, if you have any problems with 
  the above mentioned video cards visit our website and we’ll help you 
  out.

- If you experience problems with the Ensoniq 1868 VIVO, the Gravis 
  Ultrasound PnP, or the NewCom PnP sound cards, please visit our 
  website at  www.3do.com\customerservice .  We have links to these 
  company’s websites so you can download the latest drivers.  Direct X 
  5.0 didn’t have the latest drivers for these sound cards and since we’re 
  a Direct X 5.0 game, we’ll need them to run.  So, if you have any 
  problems with the above mentioned sound cards visit our website and 
  we’ll help you out.

- If you experience any graphics problems (screen is black, but you can
  hear gun fire if you mouse click, glitches in the game or in text 
  displays, etc), visit the manufacturer website and download the latest 
  drivers for your graphics card.  If this doesn’t help, visit 
  www.3do.com\customerservice
  
- On certain video cards with VESA 1.2 drivers, the background 
  mountains will disappear.  To fix this, download the VESA 2.0 
  drivers.

- If you experience any graphics problems with the 3DFX version, visit 
  the 3DFX manufacturer website, or visit 
  www.3do.com\customerservice
 
- In the 3DFX version, during gameplay, if you wish to load a game, 
  enter the load game menu and if it appears blank, move your mouse 
  cursor over the area where the saved games are.  The games will then 
  become highlighted and you can load them.

- During gameplay, if you wish to reset your graphic options to the 
  default setting, you must do it manually by clicking the arrow up or 
  down.

- In the Controls menu, if you wish to restore the mouse options to the 
  default setting, you must do it manually.

- If you ever become stuck in a building, enter your Citadel view, target 
  the building you're stuck in and sell the building.

- Microsoft's installer has been known to crash out if you're asked 
  to insert your Windows 95 disk. If this happens, re - run the installer. 
  It might crash out multiple times -- up to 5. Eventually, it gets the 
  files it needs and you'll be done with it. Sorry -- its not our 
  installation routine.




Overview:

1. Your Wraith tank is a mobile command center on the battlefield.

2. Use allied units such as infantry, tanks, AAV gunships and bombers to 
   destroy the enemy.

3. To create units, establish Citadel bases on command bunkers throughout 
   a map.

4. Build factories at Citadels to produce unit types, or mine for power 
   resource.

5. Build as many Citadels and factories as possible.  Stop the enemy from 
   doing the same!


Game Controls:

Up/Down Arrows	 ---------------Wraith forward/back
Left/Right Arrows---------------Wraith strafe left/right
Mouse		 ---------------Controls view
Left click	 ---------------Primary weapon
Right click	 ---------------Secondary weapon

F9		Calls in Citadel (Wraith must be in the claim 
		square of a command bunker)
F12		Command nearest Citadel. Cycles through	
		multiple Citadels.
F1		Deploys infantry (must have factory)
F2		Deploys tank (must have factory)
F3		Deploys AAV gunship (must have factory)
F4		Deploys bomber (must have factory)
F5		Deploys gun turret (only near claimed
		Citadel)
F6		Deploys SAM site (only near claimed Citadel)
F7		Killer satellite strike (must have factory)
F11		Toggles Wraith HUD

O    		Satellite Map
Backspace	Recalls deployed unit (unit must be targeted)
Enter		Secondary weapon menu
Shift		Deploy Unit menu 
F		Fixes Wraith (Wraith must be in the claim 
		square of a command bunker.  This command only 
		fixes your Wraith’s lasers and heat seeking 
		missiles.  Your special weapons, Cupid 	
		Missiles, etc., are replenished by power ups 	
		dropping from the sky.)


Strategies:

- Your Wraith can’t do it alone.  Remember to use you allied units to 
  conquer the map.

- If you get stuck, use different strategies.  Most of the times you will 
  become comfortable with a certain strategy and will use it forever.  Mix 
  things up.
  
- Experiment with different weapons.  You’ll love the antimatter disc...

- Build as many different unit types as possible on each map.  Diversity 
  is the key to success.
 
- Strafe.  Enough said.

- Use the Power Triangle.  You won’t realize how much you need it until 
  you use it.
